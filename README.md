# ai-delivery-sandbox — orders-portal

Учебная песочница для [ИИ-агента поставки задач](https://github.com/v0ropaev/ai-delivery-agent)
(курс «Автоматизация бизнес-процессов с помощью ИИ»).

Здесь вместо рабочих Битрикс24 и GitLab:

- **Issues** — карточки задач, которые агент заводит после квалификации заявки и подтверждения тимлида
  (метки `source:agent`, `type:*`, `size:*`, `dev:*`, `module:*`).
- **Pull requests** — на них агент проводит предревью по стандарту команды и оставляет комментарии с метками
  `blocker` / `nit` / `later`.

Сам сервис — небольшой B2B-портал заказов: заказы, счета и оплаты, отчёты, уведомления, интеграция с CRM.
Правила репозитория и no-go зоны — в [CLAUDE.md](CLAUDE.md). Команда в `dev:*` вымышленная.
