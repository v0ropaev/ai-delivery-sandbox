# orders-portal — правила репозитория

Учебный B2B-портал заказов. Песочница для ИИ-агента поставки задач: агент заводит здесь задачи (issues)
и проводит предревью pull request.

## No-go зоны (нарушение — blocker на ревью)

1. **Секреты** — только из переменных окружения (`app/config.py`). Никаких токенов, паролей и ключей в коде и логах.
2. **Персональные данные** — email, телефон, ФИО клиентов не пишутся в логи и не попадают в тексты ошибок API.
   В логах — только идентификаторы (`client_id`, `invoice_id`).
3. **SQL** — только параметризованные запросы через `app.db.query()`. Сборка SQL строками (f-string, `%`, `+`) запрещена.
4. **Права доступа** — фильтрация по правам выполняется В ЗАПРОСЕ через `acl.scope_sql()` (pre-retrieval).
   Выбрать всё и отфильтровать в Python (post-retrieval) запрещено.
5. **Миграции** — каждая миграция `NNNN_name.sql` сопровождается `NNNN_name.down.sql`.
6. **Публичный API v1** (`app/orders/api.py`) — без breaking changes: только новые поля и эндпоинты, удаление — через deprecation.
7. **Деньги** — только `Decimal`, округление `ROUND_HALF_UP` до копеек (`app.billing.money.round_money`). `float` для денег запрещён.

## Тесты

Изменения в `auth`, `billing` и `acl` обязательно сопровождаются тестами (`tests/`). Запуск: `pytest -q`.
